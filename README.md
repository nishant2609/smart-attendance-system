# Smart Attendance Monitoring System

Startup-grade attendance monitoring app using:

- Kotlin
- Clean Architecture
- Firebase
- CameraX
- ML Kit
- FaceNet

## Architecture

Multi-module Clean Architecture:
- app
- core
- domain
- data
- auth
- ml
- camera

## Features

- Role-based authentication
- Multi-admin support
- Hybrid student claim system
- Face recognition attendance
- SaaS-ready architecture

## Setup Instructions

1. Clone repository
2. Add google-services.json
3. Build project
